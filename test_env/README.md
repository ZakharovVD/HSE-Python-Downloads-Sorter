# Сортировка копии загрузок

Запуск из корня проекта:

```bash
python3 -m test_env.run_checks
```

Скрипт копирует `~/Downloads` в новую папку `test_env/runs/run-…/downloads`
и сортирует копию. Выводит её путь, количество перемещённых файлов
и список оставшихся файлов с причинами пропуска или ошибки.

Рядом с копией создаётся `moved_files.txt`: по одной строке
`'исходное имя' -> 'категория/итоговое имя'` для каждого успешного перемещения.

История копии хранится в `downloads/.sorter-state/history.sqlite3` внутри
папки запуска. Копии исключены из git.

# Сортировщик папки «Загрузки»

Индивидуальный проект по курсу Python в НИУ ВШЭ «Автоматизируй свою рутину».

**Автор:** Вячеслав Захаров.  
**Название репозитория:** `hse-python-downloads-sorter`.

## Какую рутину автоматизируем
В папке «Загрузки» накапливаются учебные материалы, документы, картинки и архивы.
Приходится вручную просматривать файлы, создавать папки и переносить в них
документы. Из-за этого нужные материалы становится сложнее находить.

Программа должна разбирать выбранную папку по настраиваемым правилам. Например,
файл `лекция_по_python.pdf` попадёт в «Учёба», фотография — в «Изображения»,
а ZIP-архив — в «Архивы».

## Возможности

- Сортировка по ключевым словам и расширениям из JSON-конфига.
- Предварительный план и подтверждение перемещений.
- Разрешение конфликтов имён суффиксом: `отчёт (1).pdf`.
- История между запусками, отмена и восстановление после прерывания.
- Поиск дубликатов по SHA-256 без удаления файлов.

Сортируются файлы верхнего уровня. Скрытые файлы, символические ссылки
и недокачанные загрузки пропускаются. Дубликаты ищутся также в папках категорий.
История хранится в `.sorter-state/history.sqlite3` внутри сортируемой папки;
отмена возвращает неизменённые файлы
на свободные исходные места, а конфликты пропускает с сообщением.

## Запуск

Требуется Python 3.12 или новее. Внешние библиотеки и подключение к сети не нужны.

```bash
cd ~/hse-python-downloads-sorter
python3 -m downloads_sorter plan
```

По умолчанию используется `~/Downloads`. Для другой папки передайте
`--source "/путь/к/папке"`.

## Команды

- `plan` — показать план без изменения файлов и создания истории.
- `sort` — показать план и выполнить сортировку после подтверждения.
- `undo` — отменить последнюю сортировку с ещё не возвращёнными файлами.
- `duplicates` — вывести группы одинаковых файлов.
- `history` — показать последние запуски; `--limit 20` изменяет число записей.

Команды: `python3 -m downloads_sorter <команда>`.
`sort` и `undo` запрашивают ответ `да` или `yes`; флаг `--yes` подтверждает действие
без вопроса. Справка: `python3 -m downloads_sorter <команда> --help`.

## Настройки

Конфиг по умолчанию: [downloads_sorter/rules.json](downloads_sorter/rules.json).
Категории задаются в `categories`: `name` — папка, `keywords` — подстроки имени,
`extensions` — расширения с точкой, включая составные вроде `.tar.gz`.
`fallback_category` задаёт папку для остальных файлов, `skip_extensions` —
расширения пропускаемых загрузок.

Сначала проверяются ключевые слова, затем расширения, без учёта регистра.
Внутри каждого этапа выбирается первая подходящая категория в конфиге.
Свой конфиг передаётся через `--config`:

```bash
python3 -m downloads_sorter plan --source ~/Downloads --config rules.json
```

Перемещения требуют поддержки жёстких ссылок и одного устройства для исходной
папки и категорий. Во время сортировки избегайте параллельного изменения файлов.

## Обработка ошибок

- Пропавший после просмотра плана файл пропускается с сообщением.
- Неверный конфиг останавливает запуск до перемещения файлов.
- Отказ в доступе выводится как ошибка, остальные доступные файлы обрабатываются.
- Занятое имя получает числовой суффикс без перезаписи существующего файла.
- Изменённый файл при отмене сохраняется на месте и отмечается как ошибка.
